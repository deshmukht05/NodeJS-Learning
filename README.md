# Node.js Coding Notes

A collection of free Node.js notes, examples, practice programs, and lecture-wise learning material.

This repository is organized into separate folders such as `Lecture-1`, `Lecture-2`, `Lecture-3`, and more, making it easy to learn Node.js concepts step by step.

## Overview

This repository contains my Node.js learning notes and coding practice.

Each lecture folder contains topic-wise material, examples, commands, and practice code related to Node.js. The notes are structured in a progressive order, starting with basic concepts and moving toward more practical Node.js topics.

The purpose of this repository is to maintain a well-organized collection of Node.js learning resources and to help beginners understand Node.js through simple examples.

## Prerequisites

Before running the code examples, make sure that Node.js is installed on your computer.

Check the installed Node.js and npm versions:

```bash
node -v
npm -v
```

If Node.js is not installed, download it from the official Node.js website:

[Download Node.js](https://nodejs.org/)

## Getting Started

### Clone the Repository

```bash
git clone [https://github.com/your-username/nodejs-coding-notes.git](https://github.com/your-username/nodejs-coding-notes.git)
```

Replace `your-username` with your GitHub username.

### Navigate to the Repository

```bash
cd nodejs-coding-notes
```

### Install Dependencies

If the repository contains a `package.json` file, install the required packages:

```bash
npm install
```

### Open a Lecture Folder

For example:

```bash
cd Lecture-1
```

### Run a JavaScript File

Use the following command:

```bash
node filename.js
```

For example:

```bash
node example.js
```

## Example

A basic Node.js program can be run with the following command:

```bash
node app.js
```

Example code:

```javascript

```

Expected output:

```text
Hello from Node.js!
```

## Important Commands

### Check Node.js Version

```bash
node -v
```

### Check npm Version

```bash
npm -v
```

### Initialize a Node.js Project

```bash
npm init -y
```

### Install a Package

```bash
npm install package-name
```

### Install a Development Dependency

```bash
npm install package-name --save-dev
```

### Run a JavaScript File

```bash
node filename.js
```

### Install All Project Dependencies

```bash
npm install
```
